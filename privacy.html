Kebijakan Privasi

Kala Senja Publisher — alat internal Hilman Studio
Berlaku sejak 27 September 2026 · kembali

1. Ringkasnya

Aplikasi ini hanya mengakses akun TikTok milik kami sendiri (artis Kala Senja). Kami tidak mengumpulkan data pengguna TikTok lain, tidak menjual data apa pun, dan tidak memakai data untuk iklan. Tidak ada pengguna pihak ketiga di aplikasi ini.

2. Data yang diakses

Melalui TikTok API resmi, dengan izin (scope) berikut:

  • user.info.basic — nama tampilan, nama pengguna, dan foto profil akun kami sendiri.
  • user.info.stats — jumlah pengikut, jumlah mengikuti, jumlah suka, jumlah video pada akun kami sendiri.
  • video.list — daftar video yang kami unggah sendiri beserta statistiknya (tayangan, suka, komentar, bagikan).

Bila kelak izin unggah (Content Posting API) diaktifkan, aplikasi hanya mengunggah konten milik kami sendiri ke akun kami sendiri.

3. Data yang TIDAK kami ambil

  • Data profil, video, atau statistik pengguna TikTok lain.
  • Komentar, pesan pribadi, atau daftar kontak siapa pun.
  • Lokasi, kontak telepon, atau data perangkat pengunjung.

Halaman ini sendiri tidak memakai cookie, tidak memasang analitik, dan tidak memuat pelacak pihak ketiga.

4. Tujuan penggunaan

Satu-satunya tujuan: memantau performa karya musik kami sendiri (berapa tayangan sebuah video, bagaimana pertumbuhan pengikut) supaya kami bisa memutuskan konten berikutnya, dan menjadwalkan unggahan konten kami sendiri.

5. Penyimpanan & keamanan

  • Data statistik disimpan di server pribadi milik pemilik studio, tidak dibagikan ke layanan lain.
  • Token akses OAuth disimpan dalam berkas dengan izin baca terbatas (hanya pemilik sistem), di luar repositori kode publik.
  • Hanya pemilik studio yang memiliki akses ke server tersebut.

6. Berbagi data

Kami tidak membagikan, menjual, menyewakan, atau menukarkan data kepada pihak mana pun. Tidak ada pengiklan, tidak ada broker data, tidak ada mitra analitik.

7. Penyimpanan & penghapusan

Statistik disimpan selama masih berguna untuk perbandingan antarwaktu. Pemilik dapat menghapusnya kapan saja. Akses aplikasi dapat dicabut kapan pun melalui TikTok → Pengaturan dan privasi → Keamanan dan izin → Kelola aplikasi; setelah dicabut, token yang tersimpan tidak lagi berlaku dan dihapus dari server.

8. Anak-anak

Aplikasi ini tidak ditujukan untuk anak-anak dan tidak mengumpulkan data dari siapa pun, termasuk anak-anak.

9. Perubahan kebijakan

Bila cakupan data yang diakses berubah, halaman ini diperbarui beserta tanggal berlakunya.

10. Kontak

Pertanyaan atau permintaan terkait data: kalasenjamusic@gmail.com

English summary. This internal tool accesses only our own TikTok account (the artist Kala Senja), using user.info.basic, user.info.stats and video.list to read our own profile and video statistics. We collect no data about any other TikTok user, use no cookies or third-party trackers on this page, and never sell or share data. Data is kept on a private server; OAuth tokens are stored in permission-restricted files outside any public repository. Access can be revoked at any time in TikTok → Settings and privacy → Security and permissions → Manage app permissions, after which stored tokens are deleted. Contact: kalasenjamusic@gmail.com
